## Общее описание
Agro AI - это комплексная система управления сельскохозяйственным предприятием, которая объединяет мониторинг полей, прогнозирование урожайности, управление техникой и автоматизацию процессов. Система предоставляет различные уровни доступа для разных специалистов и автоматизирует рутинные задачи.

## Роли пользователей

### Агроном
- Доступ к автоматическому мониторингу полей
- Просмотр прогнозов урожайности
- Формирование отчетов о состоянии полей
- Доступ к карте полей

### Аналитик
- Просмотр прогнозов
- Доступ к модулю безопасности
- Работа с картой полей

### Менеджер
- Мониторинг техники
- Просмотр прогнозов поломок
- Формирование отчетов о технике
- Доступ к карте полей

### Оператор дронов
- Управление дронами
- Мониторинг безопасности
- Формирование отчетов о полетах
- Доступ к карте полей

### Механик
- Мониторинг техники
- Доступ к отчетам о технике
- Доступ к карте полей

### Почвовед
- Доступ к автоматическому мониторингу
- Работа с картой полей

## Модули системы

### 1. Безопасность
- Мониторинг периметра полей
- Обнаружение несанкционированного доступа
- Отслеживание движения техники
- Система оповещений

### 2. Мониторинг
- Отслеживание состояния техники
- Мониторинг CAN-шины
- Отображение статусов оборудования
- Система уведомлений о неисправностях

### 3. Автомониторинг
- Отображение данных с датчиков:
  - Влажность почвы
  - Температура
  - Кислотность (pH)
  - Содержание питательных веществ
- NDVI-индексы
- Тепловые карты
- Журнал работ

### 4. Прогноз
- Прогноз урожайности
- Анализ рисков
- Рекомендации по обработке
- Прогноз поломок техники

### 5. Дроны
- Управление полетами
- Планирование маршрутов
- Мониторинг состояния дронов
- Просмотр видео с камер

### 6. Карта поля
- Интерактивная карта полей
- Отображение границ участков
- Просмотр NDVI-индексов
- Отображение техники на карте

### 7. Создание отчета
#### Для оператора дронов:
- Отчет о мониторинговых мероприятиях
- Отчет о обработке полей

#### Для агронома:
- Общий отчет показателей мониторинга
- Отчет о состоянии поля
- Отчет о прогнозировании

#### Для менеджера:
- Отчет о состоянии техники
- Отчет о затратах на обслуживание
- Отчет об эффективности прогнозов

## Руководство пользователя(кратко)

### Вход в систему
1. Откройте приложение
2. Введите логин и пароль
3. Выберите роль пользователя

### Работа с картой поля
1. Выберите поле из выпадающего списка
2. Используйте инструменты масштабирования
3. Просматривайте слои данных (NDVI, техника, границы)
4. Кликайте на объекты для получения детальной информации

### Работа с отчетами
1. Перейдите в раздел "Создание отчета"
2. Выберите тип отчета
3. Введите ФИО ответственного
4. Укажите период отчета
5. Нажмите "Скачать отчет"

### Мониторинг техники
1. Откройте раздел "Мониторинг"
2. Просматривайте статусы техники
3. Обращайте внимание на предупреждения
4. Используйте фильтры для поиска

### Работа с дронами
1. Перейдите в раздел "Дроны"
2. Выберите дрон
3. Задайте маршрут полета
4. Запустите мониторинг
5. Просматривайте данные в реальном времени

## Технические требования

### Системные требования
- Операционная система: Windows 10/11
- Процессор: Intel Core i5 или выше
- Оперативная память: 8 ГБ или более
- Свободное место на диске: 2 ГБ
- Подключение к интернету

### Поддерживаемые браузеры
- Google Chrome (рекомендуется)
- Mozilla Firefox
- Microsoft Edge

### Дополнительное оборудование
- Датчики для мониторинга
- Дроны с камерами
- GPS-модули для техники
- CAN-адаптеры для техники
